# HireSense AI

Build Smarter. Apply Better. Grow Faster.

- Build a production-oriented career intelligence platform incrementally. Stop at the boundaries of each assigned task.
- Preserve existing working code and user changes. Explain important architectural changes.
- Use a modular monolith: React/TypeScript/Vite/Tailwind presentation, FastAPI/Pydantic REST API, future application/domain services, data access and external adapters. Keep business logic independent of HTTP, databases and AI providers.
- Use npm and an isolated backend Python virtual environment. SQLite/SQLAlchemy/Alembic are planned, not implemented in Task 001.
- Target Windows with 8 GB RAM and integrated graphics. Avoid unnecessary dependencies, background services, containers and heavyweight ML packages.
- Protect resume data and personal information. Never commit secrets or log document contents, credentials or personal data. Bind local development servers to loopback and allow only explicit CORS origins.
- Core resume, deterministic ATS and document functions must eventually work without external AI. Distinguish mock functionality from real AI; never fabricate metrics or completed-feature claims.
- Run relevant tests and configured checks; report actual results and unverified behavior honestly. Keep development progress and setup documentation accurate.
- Do not commit, push or deploy without user authorization.
